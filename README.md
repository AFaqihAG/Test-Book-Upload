# Judul Buku

Sumber LaTeX buku ini ada di `src/`. Setiap `git push` ke cabang `main`
akan mengompilasi PDF dan menerbitkannya lewat GitHub Pages.

## Struktur

- `src/main.tex` — sumber buku
- `site/index.html` — halaman depan
- `.github/workflows/pages.yml` — kompilasi dan penerbitan otomatis

## Mengaktifkan GitHub Pages

Settings → Pages → Source: **GitHub Actions**.
